# Nandan B M - Professional Portfolio

Welcome to my personal portfolio website! This project is a modern, responsive, and interactive showcase of my journey as a Tech Analyst and Engineer, featuring my professional experience, certificates, projects, and skills.

## 🚀 Features

- **Interactive Capsule Navigation:** A modern floating navigation bar that dynamically highlights the active section on scroll.
- **Dynamic Projects & Experience:** Netflix-style scrollable rows showcasing professional journey highlights, skills, certificates, and projects.
- **Serverless Contact Form:** Fully functional contact form built with Go serverless functions and integrated with the **Resend API**.
- **Responsive Design:** Sleek and fully responsive layout optimized for mobile, tablet, and desktop viewports.

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3 (Vanilla), Vanilla JavaScript
- **Backend:** Go (Golang)
- **Email Service:** Resend API
- **Deployment:** Vercel

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nandan8055/nandan-portfolio.git
   cd nandan-portfolio
   ```

2. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your Resend API Key:
   ```env
   RESEND_API_KEY=your_resend_api_key_here
   ```

3. **Run the Go Server:**
   ```bash
   go run server.go
   ```
   Open your browser and navigate to `http://localhost:8080`.
